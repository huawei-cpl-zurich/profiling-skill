# Retained native SDOT runtime failure

This draft retains a source-derived native Ascend C dot-product comparison that **did not pass numerical validation**. The native source compiled and its registrations and ABI passed inspection. The first baseline API reached its sole output-storage CPU transfer, where ACL synchronization failed with `507035` (vector-core exception). No CPU output values or numerical comparison were available. The cause is unresolved; this does not establish a resource overflow, an infrastructure fault, an arithmetic defect, or a general limitation of fusion.

The complete evidence is [R11-result.json](../experiments/optimization-wave009/R11-result.json), with full compiler/runtime diagnostics in `R11-diagnostics.json.gz`. The original [R11.json](../experiments/optimization-wave009/R11.json) and prospective authoritative [R11-v2.json](../experiments/optimization-wave009/R11-v2.json) are both retained. V2 clarified resource evidence before any scientific reference or numerical API: actual compiler acceptance, ABI/code checks and exact source address/tail analysis permit bounded correctness; automatic scratch and peak resources remain unknown. No kernel, helper, tiling, flags, fixture, tolerance or arithmetic change accompanied that clarification.
